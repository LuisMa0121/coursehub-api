# Dependencias

Se conserva la base NestJS 12 del repositorio original. Verificado con Node.js 24.18.0.

La auditoría npm del 15/09/2026 informa 9 avisos transitivos (incluidos de gravedad alta), entre otros multer y undici. El informe no ofrece una actualización automática para todos ellos. Esta entrega comprueba los requisitos académicos y el funcionamiento local; no acredita preparación para producción. Antes de un despliegue público, revisar npm audit y actualizar las dependencias afectadas. No se han forzado cambios de versión mayor sobre la base del curso.
